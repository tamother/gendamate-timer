# 头马演讲计时器 MVP

## 从 AgendaMate 导入

点击“从 AgendaMate 导入”→“打开 AgendaMate”，在独立窗口登录并选择俱乐部当前已保存的议程，确认发送，再回计时器预览并确认导入。目前每个俱乐部提供一份当前云端议程；未保存的修改需先在 AgendaMate 保存。窗口不可用时，可下载计时数据 JSON 再通过文件导入。

导入包含所有环节、姓名和原定时长，建立独立会议及待计时列表。≤2 分钟匹配即兴，>2 且 ≤3 分钟匹配点评，>3 分钟匹配备稿；原定时长始终保留。缺失时长会标记待补，载入后可以调整阈值。点击“载入计时”，结束后“下一位”自动带入下一条未完成环节。重复导入相同来源会去重，保留已完成记录。

导入窗口使用 AgendaMate 本站登录和读取接口，不向计时器传递登录凭据；只有明确确认后才发送选中议程，计时器还会核对来源窗口、域名和本次导入标识。计时记录仍保存在当前浏览器，不回写 AgendaMate。

## 运行

在本目录运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000`。无需安装依赖。首次打开后，浏览器会缓存应用文件，之后断网也能在同一地址使用；首次离线打开无法安装缓存。浏览器的隐私模式或清除站点数据会删除本地配置和记录。

## 使用

选预设或自定义阈值，填写标题并开始。计时达到绿、黄、红阈值时，背景自动变色。暂停后可继续；“结束并保存”将记录保存到本浏览器，支持导出 JSON。重置会丢弃当前未结束的一轮。全屏展示可按 Esc 退出。提示音须勾选，且取决于设备、浏览器和共享软件的音频设置。

腾讯会议可直接共享浏览器窗口。OBS 可添加浏览器来源，地址填本机运行的网页地址，或通过窗口捕获浏览器；若使用浏览器来源，请先确认 OBS 能访问该地址。OBS 虚拟摄像头会把画面送到会议软件，音频仍需单独设置。

## 数据边界

`timer-core.mjs` 的任务包含 `schemaVersion`、`id`、`title`、`activity`、`agendaSource`、`thresholds`、`startedAt`、`endedAt`、`result`。`agendaSource` 预留来源、会议 ID、议程项 ID。`agenda-adapter.mjs` 提供议程项映射、读取和写入函数；当前读取返回空数组，写入不做远端操作。接入 AgendaMate 时在适配器中实现 API 并决定身份认证和同步失败处理。

## 测试

运行 `node --test test.mjs`。在网页中再检查预设切换、开始/暂停/继续/结束、纯色/数字切换、全屏、导出和断网刷新。

## 手机时间指示牌

手机访问 https://timer.gendamate.cn，设置阈值后开始计时，选择“纯色”，再点“手机指示牌 / 全屏”。颜色会铺满网页可见区域，竖屏、横屏均适用；右上角可退出，退出不会停止计时。支持原生全屏的浏览器会同时隐藏浏览器栏；iPhone 等不支持时仍铺满网页区域。可通过浏览器的“添加到主屏幕”使用独立窗口。浏览器支持时会请求保持屏幕常亮；如系统仍自动锁屏，请在手机设置中延长锁屏时间。回到后台或锁屏时无法保证颜色提示及时显示，使用时请让网页保持前台。

## 本场会议与计时员报告

新建会议并修改会议名称、日期。每轮填写姓名和环节，结束后自动保存到本场会议；点“下一位”继续。报告不展示演讲题目，按环节分组。同一人多次发言保留为多条记录。记录可修正姓名及环节，删除前会确认。切换会议可查看历史报告。

“复制报告”可粘贴微信群；“导出 CSV”供 Excel 打开（CSV 无颜色）；“预览报告 / 长图”打开本站独立报告页，可下载一张 PNG 竖版长图，人数增加时图片自动延长；“打印 / PDF”打印本场报告。JSON 备份包含所有会议与任务数据。当前没有 JSON 恢复入口。记录只在此浏览器保存，清除站点数据会丢失，请及时导出。旧版记录归入“历史记录（待整理）”，不会把旧演讲题目当作姓名。


## 分段与会议时间

第一轮开始时自动记录会议开始时间，报告以最后一条已完成记录的结束时间为会议结束时间。Closing Remarks 作为普通环节计时并结束保存即可，没有额外的整场开始或结束按钮。

分段计时仅在“即兴环节 · 总时长＋分段”类别显示。设定主持人和环节总时长（默认20分钟）后开始。醒目的总剩余时间持续倒计时，不触发绿黄红牌；全屏时仍会显示。填写发言人并新增分段，每段固定使用1/1:30/2分钟灯色。再次新增会保存上一段并开始下一段；也可先结束分段，间隔期间背景保持中性。暂停与继续同步作用于总计时和当前分段。总时间用完后显示超出时间，不改变背景。结束环节会保存当前分段及主持人的总用时。明确命名为“Table Topics Session”或“即兴环节”的导入项目会自动使用此模式。

会议、记录与报告预览仅存储在当前浏览器；报告网页地址不包含私人记录，也不会将记录上传到服务器。刷新或关闭计时页面会丢失未结束保存的本轮和分段。

## 自定义总时长

选择自定义后，只需填写总时长的分钟与秒数。超过 3 分钟且不超过 10 分钟时，自动按“剩余 2 分钟绿牌、剩余 1 分钟黄牌、时间到红牌”填写阈值，例如 8 分钟 → 06:00 / 07:00 / 08:00。三张牌均使用分、秒输入，旁边的小箭头每次增减 5 秒，也可手动微调。范围之外仍可手动设置三张牌。原有三种预设保持原阈值，开始后所有时间控件锁定。

## 多人发言（含分段）

原“即兴环节”现通用于即兴演讲、嘉宾介绍、真情分享。选择场景可带入每人三色时间，或直接修改分、秒。总时长独立设置，默认20分钟；到点时仅剩余时间栏标红，不影响当前发言人的提示牌背景。每次新增分段沿用开始环节时设置的三色时间。普通环节不显示分段工具。
